# University Database Management System

## About the Project
A University Database Management System developed using MySQL Workbench to manage students, departments, instructors, courses, enrollments, and class schedules.

## Technologies
- MySQL
- MySQL Workbench
- SQL

## Database Tables
1. Students
2. Departments
3. Instructors
4. Courses
5. Enrollments
6. Class Schedule

## SQL Concepts
- Database and table creation
- Primary and foreign keys
- Constraints
- INSERT, UPDATE and DELETE
- INNER JOIN and LEFT JOIN
- Subqueries
- Aggregate functions
- GROUP BY and HAVING
- Indexes
- Views

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Download this repository.
3. Open `university_database.sql` in MySQL Workbench.
4. Execute the SQL script.
